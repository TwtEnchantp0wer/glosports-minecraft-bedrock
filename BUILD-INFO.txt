Hardware notes
  - armhf userland: only 32-bit (armeabi-v7a) APKs can run
  - Mali-400 has no GLES 3.0: RenderDragon based Bedrock versions are unsupported
  - 512 MB RAM, no swap: only old/low-memory APKs are realistic
  - system provides SDL2, glibc, EGL/GLES, gbm/drm and freetype; they are NOT bundled
